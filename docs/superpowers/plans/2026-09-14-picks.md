# 뽑기 메뉴 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/picks`에 학생·순서·모둠·자리 뽑기 4종 + 공통 연출/소리 + DB 저장을 구현한다.

**Architecture:** Server Component(`/picks` page)가 학생·업무·저장목록을 조회해 Client 탭 UI에 전달. 추첨·배치는 클라이언트 순수함수(`pickRandom`), 효과음은 의존성 없는 Web Audio 합성(`pickSound`). 저장/순서적용만 Server Actions(`pickActions.ts`, `ActionResult` 패턴).

**Tech Stack:** Next.js 14 App Router, Prisma + SQLite, Tailwind, lucide-react, HTML5 DnD, Web Audio API.

**Spec:** `docs/superpowers/specs/2026-09-14-pick-design.md`

- [ ] **Step 1: 타입 추가** (`src/types/index.ts`末尾):
```typescript
export interface PickStudent { id: string; studentNumber: number; name: string; gender: string | null; status: string; }
export type SeatFillFrom = "front" | "back";
export type SeatGenderMode = "ignore" | "pair" | "separate";
export interface SeatConfig { divisions: number; colsPerDivision: number; fillFrom: SeatFillFrom; genderMode: SeatGenderMode; }
export interface SeatCellState { key: string; row: number; col: number; division: number; enabled: boolean; lockedGender: "남" | "여" | null; fixedStudentId: string | null; studentId: string | null; }
export type ActionResult<T> = { success: true; data: T } | { success: false; error: string };
```
- [ ] **Step 2: `pickRandom.ts` 구현** — 시그니처 고정:
```typescript
export function shuffle<T>(input: readonly T[], rand: () => number = Math.random): T[];
export function sampleCount<T>(input: readonly T[], count: number, rand?: () => number): T[];
export function dealRounds<T>(input: readonly T[], count: number, rounds: number, allowDuplicate: boolean, rand?: () => number): T[][];
export function dealGroups<T>(input: readonly T[], sizes: number[], getGender: (item: T) => string | null, separateGender: boolean, rand?: () => number): T[][];
export function buildSeatCells(config: SeatConfig, studentCount: number): SeatCellState[];
export function autoAssignSeats(cells: SeatCellState[], students: PickStudent[]): SeatCellState[];
```
규칙: `dealRounds` 중복불가인데 `count*rounds > n`이면 `throw new Error`. `dealGroups`는 sizes 합계 ≠ n이면 throw. `autoAssignSeats`는 고정 먼저 확정 → lockedGender 우선 충족 → genderMode 적용, 원본 불변(복사 후 반환).
- [ ] **Step 3: `pickSound.ts` 구현** — 시그니처 고정:
```typescript
export function isMuted(): boolean; export function setMuted(m: boolean): void;
export function playClick(): void; export function playTick(rate?: number): void;
export function playPop(): void; export function playFanfare(): void; export function playError(): void;
```
지연 생성 singleton `AudioContext`, `localStorage("pick_sound_muted")`, try/catch로 무음 실패 방지. `any` 금지.
- [ ] **Step 4: 로직 검증.** Run: `npx tsc --noEmit`. Expected: PASS. (순수함수 동작은 Task 8 브라우저 검증에서 확인)
